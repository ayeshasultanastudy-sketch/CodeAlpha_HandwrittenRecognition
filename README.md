# ✍️ AI Handwritten Digit Recognition System

## 🚀 Project Overview
This project is a Deep Learning-based web application that recognizes handwritten digits (0–9) in real time using a trained Neural Network model and a Streamlit interface.

Users can draw a digit on a canvas, and the AI model predicts the number instantly with confidence score.

---

## 🧠 Features
- Interactive drawing canvas
- Real-time digit prediction
- Deep Learning CNN model (TensorFlow/Keras)
- Instant confidence score display
- Clean and simple UI using Streamlit

---

## 🛠️ Tech Stack
- Python
- TensorFlow / Keras
- NumPy
- Pillow (PIL)
- Streamlit
- streamlit-drawable-canvas

---

## 📊 Model Details
- Dataset: MNIST Handwritten Digits Dataset
- Model: Convolutional Neural Network (CNN)
- Accuracy: High accuracy on test dataset after training
